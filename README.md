# Collectes

Application Android **Collectes** pour recevoir des rappels la veille des collectes de déchets, selon votre commune.

## Fonctionnalités

- Assistant au premier lancement (commune + heure du rappel)
- Suggestion de commune la plus proche via la position (optionnelle)
- Assistant pour autoriser notifications, alarmes exactes et rappels à l’heure
- Téléchargement automatique du calendrier officiel de l'année en cours (PDF)
- Parsing des dates de collecte (ordures, emballages, verre, encombrants, végétaux selon les communes)
- Guide du tri par type de bac, adapté à la source officielle de votre commune
- Notifications locales la veille (heure configurable, types de bacs filtrables)
- Changement d'année automatique (re-sync du calendrier)
- Fonctionne hors ligne après la première synchronisation

## Premier lancement

1. Choisir sa **commune** (manuel ou suggestion via la position)
2. Choisir l'**heure du rappel**
3. Autoriser les **notifications**, les **alarmes exactes** et (recommandé) désactiver l’**optimisation batterie**
4. L'app télécharge le calendrier (connexion Internet requise)
5. Vérifier l'écran d'accueil : les prochaines collectes s'affichent

## Réglages

- Commune
- Heure du rappel (5h à 23h, pas de 30 min, défaut 12h)
- Types de bac à rappeler
- Autorisations manquantes pour les rappels (notifications / alarmes exactes)
- Apparence (vert Collectes ou thème du téléphone)
- Lien vers le calendrier officiel (source municipale ou syndicale selon la commune)
- Politique de confidentialité
- Contact développeur (mail ou WhatsApp)
